# Nakshtralogy Localization (i18n) — Overview

Nakshtralogy supports **11 languages**: English (`en`), Hindi (`hi`),
Hinglish (`hi_Latn`), Marathi (`mr`), Gujarati (`gu`), Tamil (`ta`), Telugu (`te`),
Kannada (`kn`), Bengali (`bn`), Punjabi (`pa`), Malayalam (`ml`).

## Two layers, two agents

| Layer | What it translates | Where | Agent |
|---|---|---|---|
| **Backend** | API response **data** (planet/sign/nakshatra names, dignities, grades, karaka roles, doshas, yogas, remedies, narrative) | `app/services/report_translator.py` + router `?lang=` | [`backend_language_agent`](../../.claude/agents/backend_language_agent.md) |
| **Flutter** | UI **chrome** (section headers, tab titles, buttons, labels, captions) | `lib/l10n/app_<lang>.arb` → `AppLocalizations` | [`flutter_language_agent`](../../.claude/agents/flutter_language_agent.md) |

**Golden rule:** if a string is generated by Python and sent over the wire, the
backend agent owns it. If it is a literal typed into a `.dart` file, the Flutter
agent owns it. They never overlap — a string is translated exactly once.

## How a translated screen works end-to-end

1. Flutter screen renders static labels via `AppLocalizations.of(context)!.key`
   (translated locally from ARB).
2. Flutter calls the API with `?lang=<current locale>`.
3. Backend runs `translate_report(result, lang)` and returns data already in the
   user's language.
4. Screen shows localized chrome + localized data with no client-side data mapping.

## Quick reference — the gotchas that cause build breaks (Flutter)

1. `const` + `AppLocalizations.of(context)` → "Not a constant expression". Drop
   `const` from the parent widget.
2. No `context` in a StatelessWidget helper method → thread `context`/`l` in, or
   leave the string English.
3. Dart literals with apostrophes must use double quotes: `Text("Today's Gochar")`.
4. Import depth: `screens/x/widgets/` → `../../../l10n/gen/...`; `screens/x/` →
   `../../l10n/gen/...`.
5. Keep the key set identical across all 11 ARB files in **both** apps; regenerate
   with `flutter gen-l10n`.

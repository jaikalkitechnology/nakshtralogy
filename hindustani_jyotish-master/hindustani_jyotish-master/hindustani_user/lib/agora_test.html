How to test
  1. App ID + Certificate are pre-filled with your credentials. Pick a channel name (anything, e.g. hj-test).
  2. Click Generate token — it signs an Agora RTC token in your browser from the certificate (nothing leaves the page).
  3. Click Join channel and allow mic/camera. You'll see "joined" and your local video.
  4. Open this same file on a second device or browser tab, use the same channel name, generate a token, and Join. Each side should see/hear the other (Remote tile fills in).
  5. Use Mute mic / Stop cam to toggle. Leave to disconnect.

If join fails with an invalid-token error: the in-browser token generator may not match your SDK version. Fallback: in the Agora Console → your project → Generate Temp RTC Token for the same channel, paste it into the Token field, and Join. That always works and confirms the credentials/channel.

This mirrors the app: in the real apps the backend mints this token (from the same App ID + Certificate stored in the agora_settings table) and the Flutter Agora SDK joins the channel — exactly what this page does manually. If it works here, your Agora credentials are correct and calls will connect once the backend returns a valid token.
